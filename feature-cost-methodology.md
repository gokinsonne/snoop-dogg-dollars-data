# Feature-cost normalization

The table converts documented feature multipliers into stake-denominated costs:

- Snoop Spin = base bet × 20
- Bonus Buy = base bet × 100, 200, 400 or 800
- Theoretical maximum = base bet × 10,000

Therefore, the four Bonus Buy prices equal the cost of 5, 10, 20 or 40 Snoop
Spins. This is a cost equivalence only; it does not imply equal outcome
distributions, expected returns or profitability.

No spins were simulated. Operator configuration, jurisdiction, currency and
feature availability can differ. Full table and methodology:
https://snoopdoggdollar.org/research/snoop-dogg-dollars-feature-costs/
