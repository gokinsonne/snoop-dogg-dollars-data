# Snoop Dogg Dollars — открытые данные об игре

Версионируемый, машиночитаемый и привязанный к первоисточнику набор фактов о слоте BGaming **Snoop Dogg Dollars**.

## Состав набора

- `snoop-dogg-dollars.json` — структурированные сведения об игре и функциях.
- `snoop-dogg-dollars.csv` — компактная табличная версия.
- `feature-cost-table.csv` — нормализация стоимости Snoop Spin и Bonus Buy 100×–800×.
- `feature-cost-methodology.md` — формулы, результат и ограничения расчёта.
- `datapackage.json` — метаданные и схемы ресурсов для каталогов данных.
- `CITATION.cff` — готовая ссылка для цитирования набора.

## Источники и ограничения

Основной источник фактов об игре — [официальная страница BGaming](https://bgaming.com/games/snoop-dogg-dollars). На дату проверки провайдер указывает RTP 96,00%, очень высокую волатильность и максимальный выигрыш 10 000×.

Набор отделяет данные провайдера от условий казино. Доступность, методы оплаты, KYC, бонусы, лимиты и вывод средств необходимо проверять в живой версии игры и кассе оператора.

Полная методология: [редакционная политика SnoopDoggDollar.org](https://snoopdoggdollar.org/editorial-policy/). Каноническое исследование: [Snoop Dogg Dollars Feature Cost Data Lab](https://snoopdoggdollar.org/research/snoop-dogg-dollars-feature-costs/).
